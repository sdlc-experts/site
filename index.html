Common questions

We already use Claude Code. Why do we need this?

Having the tool isn't the same as having the workflow. The demo shows the specs, gates and review that turn usage into faster merges instead of more PRs to review.

Security won't let agents near our code.

Permissions and gates are part of the setup: what agents may touch, where a person signs off, what runs only in CI.

Does the decision wiki change things on its own?

No. Agents propose entries; a person approves each one before any agent follows it.
