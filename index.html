How it flows

From a Slack message to a merged PR, with people deciding where it counts.

  1. 1 · anyoneRequestA bug or idea arrives by Slack or email.
  2. 2 · agentSpecIt becomes a spec and plan an agent can execute.
  3. 3 · tech teamApproveAn engineer signs off before any code is written.
  4. 4 · agentBuildThe coding agent implements, tests and opens the PR.
  5. 5 · CIAI reviewAutomated checks catch agent mistakes first.
  6. 6 · developerApprove & mergeA focused review of what needs judgment.

Every approval feeds the decision wiki, so the next spec starts from everything your team has already decided.
